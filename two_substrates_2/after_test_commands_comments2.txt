The 8/24 control is the surprise, and it changes how to read the whole table.

4	28	100.0%	28.2%	27.1%

4/28 is clean. The control sits at chance, so the prefix carries all four channels.
8/24 is partial, and the floor is elevated. The control lands 11 points above the analytic chance, about 7 standard errors. The masked baselines showed the same pattern with no prefix at all (28.9% at 8 removed, 33.3% at 16), so it comes from the host or the scoring, not from the head.
The honest prefix-attributable number at 8 is about 28 points (64.8 − 37.2), not the 39 you'd get against analytic chance. That's roughly 44% of the recoverable range at 8, against 100% at 4.
B is unaffected at 99.1% matched and 99.5% control.

I can't explain the elevated floor from what I have. A deterministic guess should score exactly 1/M per channel on uniformly drawn values, so guessing alone doesn't explain it. One thing I can check is whether the generation can produce more than one guess per channel. It runs up to 350 tokens, and a repeated NAME=value list would give two shots at each channel, since any match counts as a hit. Another is that the effect could be concentrated in a few channels. The script logs only aggregates, so I'll add per-channel accuracy and a repeated-name counter.
