  1. Kind? declaration · assignment · bare expression · control · type-only (runs nothing → stop)
  2. Source? literal · call · property read · operator · await · destructure
  3. Prim / Obj? string number boolean undefined null → by value. Else → by address.
  4. Ticket? async · : Promise< · fetch / db / .then / new Promise · body returns one → needs await / return / .then / Promise.all
  5. Nothing? ? prop · find · map.get · arr[i] · headers/query/params · fall-off-end · ?. → is next . guarded? (!x also eats 0 "" false)
  6. Who else? new address (literal, spread, map/filter, clone) or alias (= a, param, find, get, return this.x)? mutated? who holds it?
  7. Kept? assigned · returned · awaited · passed · used in if → else dropped: dead line or fire-and-forget

Card 2 · The review

Reading order (whole program)

  1. Clauses — rewrite the requirement as numbered facts
  2. Types — every ?, | null, any
  3. State — anything outside a function: shared, races, leaks
  4. Signatures — params, return type, async?
  5. Bodies — entry points, card per line
  6. Helpers — at the moment they're called, with the caller's values
  7. Lifecycle — timers, listeners: cleared? unref'd? removed?
  8. Clauses again — point each at a line, or write "not implemented"

Check order (severity)

requirement → =/== → boundary (limit, ±1) → await → nothing → input (undefined "" 0 −1 NaN "abc" huge) → mutation / who else → kept → errors (try+await, res.ok, swallow) → trust (SQL, URL, auth order, id from token) → race (read-await-write) → growth (no eviction, timer) → return paths → efficiency

Rank → verdict

aviolates a clause / crashes on real input1–2 · reject / changes
b–dedge input · security · leak or race2–3 · request changes
e–gdesign limit · efficiency · style4–5 · approve w/ notes
Finding = line → consequence → fix, one sentence each. Two real positives always. "Possible, not confirmed: …" beats a wrong certainty. Never default to 3.
